Автоматическая проверка обновлений через GitHub и команда «Проверить обновления…» в меню приложения.

Подлинность архива и ленты обновлений проверяется подписью Ed25519. Установка обновления ждёт завершения передачи файлов.

Сохранены окно передач с прогрессом каждого файла и отдельной отменой, контрастное освещение моделей и переключение превью стрелками.
