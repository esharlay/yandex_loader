Нажмите на имя файла в верхней части 3D-превью, чтобы переименовать модель. Enter сохраняет новое имя, Esc отменяет ввод. Расширение файла сохраняется, счётчик файлов показывается отдельно от имени.

Переименование обновляет исходный файл и списки панелей без повторной загрузки геометрии: ракурс, масштаб, камера и освещение остаются прежними. Поддерживаются локальные модели и Яндекс Диск.

Следующий снимок получает новое имя: hero.stl → New Hero.stl → New Hero.webp. Можно ввести новое имя и сразу нажать «Снимок»: приложение сначала завершит переименование, затем сохранит изображение.
