# Выпуск обновлений

Репозиторий: https://github.com/esharlay/yandex_loader

## Обычный выпуск

1. Внести изменения в исходники, проверить `./test.sh` и приложение.
2. Увеличить `version` и **обязательно `build`** в `Release.json`, обновить `RELEASE_NOTES.md`.
3. Опубликовать изменения в `main`. Изменение `Release.json` запускает GitHub Actions: проверки, сборка на Apple Silicon, ad-hoc подпись и ZIP в GitHub Releases. `GITHUB_TOKEN` выдаётся только на время этой сборки. Личные токены и Apple Developer Account не нужны.
4. На Mac владельца скачать **именно опубликованный ZIP** из релиза. Не перепаковывать и не заменять архив после подписи.
5. На этом Mac выполнить:

   ```sh
   python3 scripts/prepare-update.py /путь/к/Yandex-Loader-1.4.0.zip
   ```

   В имени архива должна быть выпускаемая версия. Скрипт сверяет данные приложения, ключ и предыдущую подписанную ленту, подписывает архив и новую ленту, затем проверяет обе подписи. Инструменты Sparkle скачиваются в `.build/` с проверкой закреплённой SHA-256 суммы. Закрытый ключ читается самим инструментом из Связки ключей и не выводится.

6. Опубликовать полученный `appcast.xml` в `main`. Это открывает обновление для установленных приложений. Изменение одной ленты не запускает повторную сборку.
7. Проверить «Проверить обновления…» в предыдущей установленной версии и переход на новую.

Codex может выполнить публикацию исходников и ленты через подключённый GitHub. Для выпуска с другого Mac потребуется перенести ключ владельца безопасным способом. Остальным Mac, которые только пользуются приложением, ключ не нужен.

## Ключ

Учётная запись ключа: `com.blueeggs.yandexloader.updates`. Закрытый ключ находится в локальной Связке ключей; публичная часть хранится в `Release.json` и приложении. Не создавайте новый ключ при обычном обновлении и не изменяйте `publicKey`.

Для резервной копии официальный `generate_keys` поддерживает экспорт `-x` и импорт `-f`. Экспортировать следует только в защищённое хранилище владельца. Ключ нельзя помещать в GitHub, исходники, ZIP приложения или переписку. При потере единственного ключа придётся вручную переустановить приложение на всех Mac.

## Ограничения

Приложение рассчитано на macOS 14+ и процессоры Apple Silicon. Сертификат Developer ID и нотариальное заверение не используются, поэтому macOS может запросить разрешение запуска и повторный доступ к сохранённому токену после замены приложения.

Первую копию установите в «Программы». При запуске из защищённой папки «Документы» macOS может блокировать замену приложения отдельным установщиком Sparkle, даже если само приложение имеет доступ к этой папке.

Готовые архивы релизов не перезаписываются. При ошибке выпуска увеличьте номер версии и сборки и выпустите исправление. Для отката поведения также выпускается новая версия с большим `build`.
